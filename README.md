# АвтоРучка для ПК

Десктопное приложение **АвтоРучка** — генератор реалистичных рукописных конспектов на фотографиях тетрадных листов. Введите текст, выберите почерк и цвет чернил, загрузите фото страниц, подгоните границы и сетку (`3×3` или `4×4`) — и сохраните результат в PDF или PNG.

Также доступна мобильная версия — [АвтоРучка для Android](https://github.com/androe123/AutoPen-Android).

## Скачать

Готовый `AutoPen.exe` — во вкладке [Releases](https://github.com/androe123/AutoPen/releases) (или соберите самостоятельно через `pywebview` и PyInstaller).

Требуется Windows 10 и новее (или Python с `pywebview` при запуске из исходников).
